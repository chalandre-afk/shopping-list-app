\# Shopping List / Grocery Planner



A small full-stack app for managing a shopping list.



\- \*\*Backend (`api/`):\*\* Node.js + Express REST API with in-memory storage

\- \*\*Frontend (`front/`):\*\* React (Vite) with react-router-dom



\## Project structure



```

shopping-list-app/

&#x20; api/     Backend (Node.js + Express)

&#x20; front/   Frontend (React)

&#x20; README.md

```



\## Prerequisites



\- Node.js 18 or higher

\- npm



\## How to run the backend (api)



```bash

cd api

npm install

node server.js

```



The API runs on \*\*http://localhost:1701\*\*.



\## How to run the frontend (front)



Open a second terminal (the backend must stay running):



```bash

cd front

npm install

npm run dev

```



The app runs on \*\*http://localhost:5173\*\*. Open http://localhost:5173/list in your browser.



\## Pages



| Route | Purpose |

|---|---|

| `/list` | Shows all items, with checkbox, delete, "Add Item" and "Clear List" |

| `/list-item/:id` | Shows one item's details; mark complete or delete it |

| `/create` | Form to add a new item |



\## API endpoints



| Method | Endpoint | Description |

|---|---|---|

| GET | `/items` | Summary of all items (no description) |

| GET | `/items/:id` | One full item |

| POST | `/items` | Create an item (`title`, `description`) |

| PUT | `/items/:id` | Update an item (`completed`) |

| DELETE | `/items/:id` | Delete one item |

| DELETE | `/items` | Clear all items |



\## Assumptions



\- Data is stored in memory only, so the list resets to empty whenever the backend restarts.

\- The list starts empty, so "No items yet" shows on first load.

\- Item ids are generated by a simple counter on the backend and are never reused.

\- The backend runs on port 1701 and the frontend on port 5173. The frontend calls the backend at `http://localhost:1701`.

\- A title is required to create an item (validated on both the frontend and the backend). The description is optional.

\- The detail page always fetches the item from the backend, so it works when opened directly by URL.

\- `/` redirects to `/list`.

\- Vite was used instead of Create React App, which is deprecated. Next.js was not used, as requested.
